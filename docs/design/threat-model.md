# 威胁模型与数据/证据边界（阶段二）

- 日期：2026-08-26

## 资产

1. 项目材料（剧本、大纲、会议转写、笔记）——可能含未公开 IP 与个人信息（PII）。
2. 人工决定与审核历史——创作决策链的完整性。
3. 可选 LLM 端点配置（base_url/api_key）。

## 信任边界

- **工作区目录** = 信任域边界。默认情况下任何字节不离开本机。
- **可选 LLM**：仅在用户显式配置并启用时，向用户指定的端点发送用户指定的内容；默认回环地址；发送前在日志中明示目标端点与内容字节数。
- **开发期工具**：pip-audit 需联网查漏洞库（发送依赖清单：包名+版本），仅开发期运行，文档注明；detect-secrets 用 `--no-verify` 保持离线。
- **外部网站/登录态**（网文模式、第三方转写平台）：视为不稳定依赖；不做任何自动登录与抓取；用户手工导出后导入。

## 威胁与缓解

| 威胁 | 缓解 |
|---|---|
| 恶意/畸形 PDF 触发解析器 DoS | pypdf 钉 ≥6.16.2；页级内容流大小上限与逐页异常隔离；扫描件只警告不 OCR |
| 依赖供应链投毒 | 依赖钉下限版本；pip-licenses 门禁；pip-audit（开发期）；SBOM 随发布物 |
| 秘密/密钥入库 | detect-secrets 基线 + 自研审计脚本（绝对路径、密钥模式、媒体/数据库/运行产物） |
| 转写 PII 泄漏 | 全部本地处理；handoff 只含工作区内引用；文档警示用户勿把工作区同步到公共位置 |
| 说话人被自动改名/伪造归属 | 未知说话人一律 `UNKNOWN` 或原标签；更名仅经 review 覆盖层，历史可恢复 |
| 自动结果被当成人工结论 | 分层存储（raw/normalized/candidates/review）；候选必须人工 confirm；产物标注层级 |
| 模型输出伪造成功 | LLM 不可用时硬性报错（exit 2 + 可操作提示）；确定性功能零 LLM 依赖 |
| 审计器误报/漏报 | 审计脚本输出机器可读报告；误报走显式 allowlist 文件，不得静默跳过 |

## 人工控制边界（不可违反）

- 前提、结构、人物主动选择、因果链、关系阶段、事件覆盖、集尾钩子、制作边界：工具只能列出「未锁定项」与证据，锁定动作必须由人执行。
- IP/版权授权、平台合规、审美取舍、最终改稿、说话人命名：不做、不替人做。

## 数据生命周期

`sources/`（原始，导入后只读）→ `normalized/`（确定性，可删可重建）→ `analysis|meetings|stages` 的 `runs/<run_id>/`（每次运行新目录，永不覆盖）→ `candidates`（自动候选）→ `decisions/review`（人工层，append-only）→ `tasks`（建议，不执行）。删除策略：normalized 与 runs 可安全删除重建；sources、decisions、review 不得由工具删除。

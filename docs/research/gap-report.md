## 自研项汇总与理由

1. **中文剧本规范化层**：全部 Fountain 候选均为英文约定（源码级证据），必须自研前缀映射与强制语法适配。
2. **BM25 检索**：rank_bm25 休眠且硬依赖 numpy、不做分词；自研百行可闭环保留确定性。
3. **情绪词表**：NTUSD/DUTIR/BosonNLP/HowNet 均不可再分发，自研小型词表是唯一合规路径。
4. **统计/结构信号/八维提示/版本比较/决定状态机/会议压缩/阶段运行器/导入与场次索引**：均为本产品领域逻辑，不存在可复用候选，自研；设计目标为可复算、可测试、证据可溯。
5. **LLM 客户端**：协议公开且极简，裸 HTTP 自研以维持零重依赖与默认离线。

## 结论

无一个功能域因「没有明星项目」而被迫自研；所有自研决定均有明确的许可证、合规、维护状态或领域适配证据支撑。最大合规风险（情感词典、PyMuPDF、pysrt）已在选型阶段规避。

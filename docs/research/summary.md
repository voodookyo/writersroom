# 一页结论摘要（阶段一）

- 日期：2026-08-26 ｜ 方法：四域并行公开来源调研（官方文档/源码/发布记录优先），全记录见 `candidate-matrix.md`

## 结论

**技术底座：Python 3.10+ 单仓 CLI，运行时在默认配置下完全离线。**

- **直接采用**：pypdf（≥6.16.2，BSD-3）、srt（MIT）、webvtt-py（MIT）、python-frontmatter（MIT）。
- **适配封装**：screenplain（MIT，Fountain 解析；中文规范化层自研）、python-docx（MIT；东亚字体与页码域走 oxml 封装）、jieba（MIT，仅作可选分词后端，默认回退字符 n-gram）。
- **自研替代**：BM25 知识检索（对照 rank_bm25 公式）、中文情绪启发式词表（三大公开词典均不可再分发）、轻量阶段运行器（doit 过重且低带宽维护）、领域逻辑全家（统计/八维提示/版本比较/决定状态机/会议压缩/场次索引/项目导入）。
- **排除**：PyMuPDF（AGPL）、pysrt（GPL-3.0）、whoosh 家族（维护链断裂+供应链风险）、snownlp（领域错位）、LM Studio（闭源，仅文档引导为用户自备端点）。
- **开发期审计**：pip-licenses（许可证门禁）、detect-secrets（秘密）、cyclonedx-bom（SBOM）、pip-audit（漏洞，联网、仅开发期）。

## 关键风险（残余）

1. python-docx 单维护者无 CI；pypdf CVE 频发需钉版+护栏；jieba 冻结且词典权利链未确认 → 均以适配层隔离，可替换。
2. 腾讯会议/讯飞听见导出文件内部精确排版未确认 → 导入器宽容解析、逐条标注来源与置信，拿到真实样本后二次校准。
3. LLM 能力为可选附加，缺失时一切确定性功能不受影响，错误信息明确可操作。

# 盲比 / 黑盒比较报告（阶段四）

- 日期：2026-08-26
- 比较对象：本机 `openusage/` 仓库（OpenUsage，含运行中的本机安装实例）
- 方法约束：黑盒（仅用户可见文档、CLI --help、本地 API 实测）；未阅读其内部实现；不以目录相似度/代码行数/界面相似度判定
- 本方：writersroom v0.1（docs/capabilities.md 为能力基线）

## 0. 前提性发现：品类不同

**OpenUsage 是 macOS 菜单栏应用，用于集中显示 AI 编程订阅的用量/额度/估算花费（12 家 provider）。**
它与本提示词的影视创作研发需求**功能零重叠**。因此「功能覆盖与用户任务完成度」维度不可逐项对比——
逐项映射的结果是：剧本研发 0/0、故事开发 0/0、会议证据 0/0、通用工具 0/0（对方均无对应能力）。
此结论本身就是最重要的比较结果：本机快照不构成该需求域的既有实现，writersroom 无重复造轮问题。

## 1. 可比较维度（跨品类通用工程实践）

| 维度 | OpenUsage（黑盒证据） | writersroom（验证证据） |
|---|---|---|
| 默认网络行为 | 有多项默认开启的联网：PostHog 匿名统计（默认开，可关）、定价表定时拉取、Sparkle 更新检查 | **默认零网络**；唯一联网面是显式配置的本地 LLM 端点（默认关闭） |
| 本地优先 | 花费计算本机完成、内置定价快照可离线启动（docs/privacy.md）；但定位依赖云端 provider API | 全部确定性功能纯本地；证据仓为纯文件 |
| 凭证/隐私 | 复用本机凭证、Keychain、原子写入；本地 API 仅 loopback（已实测 `lsof` 验证 127.0.0.1:6736）；CORS `*` 在文档中自承风险 | 无凭证需求；转写 PII 不出工作区；审计脚本防密钥入库（test_audit 全绿） |
| 证据/可恢复分层 | 不适用（无创作证据概念）；有 5 分钟共享缓存与 --force | 原始/规范化/自动候选/人工决定四层，重跑不覆盖，restore 可恢复审核历史（test_meetings） |
| 安装复杂度 | `brew install --cask`（GUI 应用，macOS 15+）；开发构建 SwiftPM、仅 3 个第三方依赖 | `pip install -e .`（Python 3.10+）；运行时硬依赖 4 个（+3 个可选 extras） |
| 文档诚实度 | 好：明确标注 deprecated 契约、CORS 风险、隐私自白 | 好：`docs/capabilities.md` 按六级诚实分级；LLM 真实端点联调标为「协议约定」 |
| 错误语义 | CLI 退出码 0/2/3/4、API 204/404/405/503 有文档（实测一致） | 退出码 0/1/2；错误一律带「解决：」可操作提示（test_cli 断言） |

## 2. 新增发现（快照中存在、本提示词未写的需求）

均来自 OpenUsage 品类本身，**不影响本需求域**，评估后**不纳入** writersroom：

1. 用量配额可视化/菜单栏钉选/配速预测——品类特有，与创作研发无关。
2. PostHog 匿名统计（默认开启）——**明确不采纳**；与本地优先/零遥测原则冲突，威胁模型已排除遥测。
3. iCloud 多机同步——可能的功能延伸，但引入云端信任边界；维持「工作区即目录、用户自选同步方式」不内置。
4. Sparkle 自动更新/签名公证——macOS 应用分发机制；Python CLI 走 pip，不适用。
5. 本地 HTTP API（loopback 只读）——有意思的工程形态；writersroom 的方案 B（本地 Web UI）若启动可参考其「仅 127.0.0.1 + 文档化 CORS 风险」做法，目前仍为延后项。

## 3. 有意差异 / 缺陷 / 待办

- **有意差异**：零遥测 vs 对方默认开启匿名统计；纯 CLI vs 原生 GUI；文件证据仓 vs 无持久层。
- **本方缺陷（自评）**：CLI 对非技术用户有门槛；LLM 真实端点未联调（协议约定级）；腾讯/讯飞真实导出样本未校准。
- **待办**：方案 B 本地审阅 UI；真实材料上的词表校准；pip-audit 联网巡检（开发期）。

## 4. 结论

黑盒比较未发现在同一需求域的既有实现可借鉴或需对齐；writersroom 的独立设计与实现成立。
OpenUsage 在文档诚实度与 loopback API 隐私自白方面的做法值得肯定，已各记一条可参考点（见 §2）。
